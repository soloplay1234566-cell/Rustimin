# Rustimin

Музыкальное приложение для **Windows 10/11 x64** с интерфейсом по видеореференсу: тёмное стекло, фиолетовое свечение, розовые синхронные строки, виджеты и постоянный плеер. Работает также в современном браузере.

## Запуск готовой Windows-версии

1. Распакуйте **весь** архив `release/Rustimin-1.0.0-Windows-x64.zip` в отдельную папку.
2. Запустите `Rustimin.exe` из этой папки. Остальные файлы нужны приложению.
3. Нажмите «Добавить музыку» или перетащите аудиофайлы в окно.

Это переносимая сборка без установщика. Node.js для запуска готового приложения не нужен. Профиль и импортированные файлы сохраняются в пользовательском каталоге приложения `%APPDATA%/Rustimin` (точное имя каталога зависит от Electron). Закрытие окна не удаляет медиатеку. Перенос папки программы не переносит профиль.

## Что работает

- Полное воспроизведение локальных MP3, WAV, OGG, FLAC, M4A/AAC и Opus при поддержке кодека Chromium.
- Импорт нескольких файлов и drag-and-drop. Файлы копируются в локальный IndexedDB; оригиналы не изменяются. Медиатека и тексты переживают перезапуск.
- Пауза, перемотка, предыдущий/следующий трек, случайный порядок, повтор трека, громкость и отключение звука.
- Избранное, поиск по названию/исполнителю, просмотр очереди, удаление из медиатеки.
- Синхронные LRC-тексты: временные метки, несколько меток в строке, offset. Клик по строке перематывает трек.
- Радио России, США, Великобритании, Франции, Германии, Японии, Южной Кореи и Бразилии через Radio Browser. Есть поиск, избранное и добавление прямых MP3/AAC-потоков.
- Три оригинальных инструментальных трека по 64 секунды включены в поставку. Это самостоятельные композиции, а не записи из референса. Текст первого трека — атмосферные визуальные строки, не транскрипция вокала.
- Системные медиакнопки, полноэкранный режим, уменьшение анимации, адаптивная компоновка.

Виджет «Пульс музыки» показывает громкость и декоративную анимацию; это не измерение пульса или BPM. «Маршрут» открывает очередь.

Радио требует интернет. Страна станции не гарантирует язык каждой песни; эфир и географические ограничения определяет вещатель. Ссылки на страницы сайтов, YouTube и Spotify не являются прямыми аудиопотоками. Каталога всех коммерческих песен по запросу в приложении нет: для прослушивания конкретного полного альбома импортируйте свои аудиофайлы.

## Разработка

Node.js 22.12+ (проверено на 24.19.0), npm. Команды выполнять из корня репозитория:

```sh
npm ci
npm run dev
```

Для настольного окна:

```sh
npm run desktop
```

Для релизной сборки:

```sh
npm run build
npm run package:win
```

Windows ZIP можно собрать на Linux. Результат — `release/Rustimin-1.0.0-Windows-x64.zip`. На Linux для запуска окна нужен X11/Wayland; web-версия и сборка работают без графической сессии.

В облачной среде с HTTP-прокси загрузчику Electron нужны:

```sh
export ELECTRON_GET_USE_PROXY=1
export GLOBAL_AGENT_HTTP_PROXY="$HTTPS_PROXY"
npm ci
```

Существующие настройки TLS и сертификаты сохраняются. Шрифт, иллюстрации и комплектные треки локальные; Google Fonts и другие CDN при запуске не нужны.

## Проверки

```sh
npm test
npm run test:e2e
```

Для браузерных проверок конфигурация использует `/usr/bin/chromium`. На другой машине установите браузер (`npx playwright install chromium`) и передайте `CHROMIUM_PATH` либо измените путь в конфигурации. Playwright сам запускает Vite.

Шесть модульных проверок охватывают LRC, длительность, имена файлов и допустимые URL. Пять браузерных сценариев проверяют реальное воспроизведение, перемотку, импорт и сохранение аудио/LRC, избранное/удаление, страны и поиск радио, отказ сети, пользовательские станции и ширину интерфейса. В радио-сценариях каталог подменён контролируемыми ответами, а аудиопоток — локальным MP3: эти тесты не подтверждают доступность внешних станций.

Релизный интерфейс также проверен в настоящем окне Electron на Linux: запуск, изолированный preload и воспроизведение локального аудио. Для повторения при наличии графической сессии: `node scripts/smoke-desktop.mjs`. Переменная `RUSTIMIN_APP` позволяет проверить конкретный `app.asar`. Параметр `RUSTIMIN_TEST_NO_SANDBOX=1` предназначен только для тестового запуска в ограниченном CI; обычное приложение не отключает sandbox.

Windows-сборка создаётся в Linux; запуск на настоящей Windows в этой среде недоступен.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| Пробел | Воспроизведение / пауза |
| ← / → | Перемотка на 5 секунд |
| Ctrl + ← / → | Предыдущий / следующий трек |
| Esc | Закрыть очередь или диалог |

Клавиши не перехватывают ввод в текстовых полях и кнопках.

## Структура

- `src/` — React, TypeScript, CSS; IndexedDB и модель плеера.
- `electron/` — изолированный процесс окна и минимальный preload.
- `public/art/` — оригинальные SVG-иллюстрации.
- `public/audio/` — готовые оригинальные треки.
- `scripts/generate_audio.py` — воспроизводимый синтез треков (только для регенерации нужны NumPy и ffmpeg).
- `tests/` — модульные и браузерные проверки.

Приложение не отправляет локальные аудиофайлы на сервер. Поисковые запросы радио передаются Radio Browser; при воспроизведении браузер связывается с вещателем. Electron работает с `contextIsolation`, sandbox и отключённым Node.js в интерфейсе; внешние окна и переходы заблокированы.
